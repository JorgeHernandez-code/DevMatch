# DevMatch Web

Frontend de DevMatch, construido con **Next.js (App Router) + TypeScript + Tailwind CSS**.

Actualmente es una landing que presenta el proyecto. El dashboard (gestión de
vacantes, perfiles de candidatos y resultados de matching) está en el roadmap.

## Puesta en marcha

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Scripts

```bash
npm run dev     # servidor de desarrollo
npm run build   # build de producción
npm run start   # sirve el build
npm run lint    # eslint
```
